About This Site

UNCG Campus Events is a listing site built as a student web design project. The goal is to give Spartans one place to check for things to do on campus instead of a dozen separate club emails.

This is not an official UNC Greensboro website. It's a class project made using UNCG's real school colors and campus landmarks, with example event listings.

  • One place to check instead of a dozen separate club emails
  • Accessibility and admission info listed for every event
  • A simple layout that works on both desktop and mobile
